# GG Squad

Приложение для геймеров: поиск тиммейтов, пати-лобби, кланы, общий чат и личные сообщения, мини-игры с друзьями, медали, уровни и рекорды. Оформление — один аккуратный стиль в четырёх расцветках: Blood, Frost, Royal и Violet. Языки: RU, EN, CS.
